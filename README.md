# Jaimin Suthar: Portfolio

Live site: https://jaimin001607.github.io/Portfolio/

Static site built with plain HTML/CSS/JS. There's no build step.

- `index.html`: home page (intro, about, stats, projects, CAD gallery, experience, skills, contact)
- `project.html?id=<id>`: detail page for each project
- `assets/data.js`: **all content** (profile, projects, experience, skills, gallery)
- `assets/img`, `assets/video`: media

To preview locally:
```bash
python3 -m http.server 8765
```
